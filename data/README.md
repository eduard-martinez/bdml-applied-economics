# Datos del curso

Los tres conjuntos de datos que atraviesan el curso — panel de mesas electorales colombianas con características censales, precios de vivienda en Bogotá e imágenes satelitales — se publicarán aquí.

> **Nota:** GitHub rechaza archivos de más de 100 MB. Los datos grandes van comprimidos o se publican por fuera (Dropbox u otro servicio) y se enlazan desde la página del curso.
